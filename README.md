# ZEROHUBUIAL — Web APK Builder

Платформаи вебие, ки дар он корбар лоиҳаи HTML/CSS/JS месозад, онро дар браузер
иҷро мекунад (RUN), бо ёрии Зеҳни сунъӣ таҳрир мекунад ва баъд ба APK-и воқеии
Android табдил медиҳад — тавассути муҳаррики берунии **H2APK**
(https://github.com/HashShin/H2APK).

## Чӣ гуна кор мекунад

- Худи вебсайт танҳо бо **HTML + CSS + JavaScript** сохта шудааст. Ҳеҷ Kotlin,
  Java, Gradle ё Android Studio дар сохтани худи сайт истифода нашудааст.
- Ҳамаи лоиҳаҳо, файлҳо ва таърихи чат дар **дастгоҳи худи корбар** (IndexedDB +
  localStorage) нигоҳ дошта мешаванд.
- API Key-ҳои Зеҳни сунъӣ ҳаргиз ба ягон сервери ZEROHUBUIAL фиристода
  намешаванд — дархост мустақиман аз браузери корбар ба хизматрасонии
  интихобшуда меравад.
- Сохтани APK тавассути H2APK иҷро мешавад — ё нусхаи худмизбони шумо
  (тавсияшуда), ё хизмати ҷамъиятии `h2apk.hashcode.win`.

## Роҳандозӣ

Файлҳоро дар як сервери статикӣ пахш кунед (масалан `npx serve` ё ҳамин хел),
зеро баъзе қобилиятҳо (IndexedDB, fetch, EventSource) аз `file://` бо
маҳдудият кор мекунанд:

```bash
npx serve .
```

Баъд `assets/intro.mp4`-ро худатон гузоред (ихтиёрӣ — агар набошад, экрани
эҳтиётии logo нишон дода мешавад).

## ⚠️ Ҳолати воқеии интегратсияи H2APK (МУҲИМ — бо диққат хонед)

Тибқи талаботи лоиҳа, ҳеҷ endpoint ё формати JSON набояд тахмин карда шавад.
Мо чор endpoint-и **воқеан тасдиқшудаи** H2APK-ро (аз README-и расмии он)
истифода мебарем:

- `POST /api/build`
- `GET /api/status/{id}`
- `GET /api/log/{id}` (SSE)
- `GET /api/download/{id}`

Аммо номи дақиқи майдонҳои JSON-и бадани дархости `/api/build` (масалан
`appName` ё `app_name`) аз коди воқеии сервер (`internal/app`) тасдиқ карда
**НАШУДААСТ**, зеро баррасии дарахти пурраи GitHub ва JS-бандли фронтенди
зинда дар вақти таҳлил дастнорас буданд. Майдонҳои дар `js/build-api.js`
истифодашуда бар пояи номҳои воқеии майдонҳои формаи зиндаи H2APK гузошта
шудаанд — «беҳтарин тахмини мустанад», на далели 100% тасдиқшуда.

**Натиҷа:** барнома ҳеҷ гоҳ намегӯяд "APK сохта шуд", агар сервер воқеан APK
барнагардонда бошад. Агар H2APK хатои валидатсия диҳад (масалан номи майдон
нодуруст бошад), он хатои **воқеӣ**-и сервер айнан ба корбар нишон дода
мешавад (дар экрани "Табдил ба APK"), на бо натиҷаи қалбакӣ пинҳон карда
мешавад.

### Барои гирифтани 100% мутобиқат — қадами ҳатмӣ

Азбаски ин масъала бидуни дидани коди воқеии сервер ё дархости воқеии
браузер ҳал намешавад, роҳи ягонаи дурусти тасдиқ ин аст:

1. H2APK-ро худ бо `go build` созед ва локалӣ роҳандозӣ кунед (нигаред ба
   `build-server/README.md`).
2. UI-и худи H2APK-ро дар браузер кушоед, формаро пур кунед ва фиристед.
3. Дар DevTools → Network дархости воқеии `POST /api/build`-ро бинед —
   номи дақиқи майдонҳо ва шакли ҷавоб дар он аст.
4. Он номҳоро дар `js/build-api.js` → `buildFormToPayload()` ва
   `startBuild()`/`getStatus()` мутобиқ созед (агар фарқ дошта бошанд).

То он вақт, барнома **воқеан** ба H2APK дархост мефиристад ва хатои
воқеиро нишон медиҳад — аммо агар номи майдонҳо мувофиқат накунад, сервер
эҳтимол хатои 400/422 медиҳад, ки матни он айнан нишон дода мешавад.

## Дигар қисмҳо — ҳолати корӣ

Инҳо бидуни вобастагӣ ба H2APK пурра ва воқеан кор мекунанд (агар API Key-и
дуруст ворид карда шавад):

- Лоиҳаҳо, файлу папкаҳо (эҷод/тағйир/нест/нусха/ҷойивазкунӣ) — 100% воқеӣ.
- Муҳаррири код бо рақами сатр ва равшанкунии синтаксис — воқеӣ.
- RUN — воқеан HTML/CSS/JS-ро дар iframe-и sandbox иҷро мекунад, консол
  хатогиҳои воқеии JavaScript-ро нишон медиҳад.
- Зеҳни сунъӣ (чат, ислоҳи хатогӣ, амалҳои файлӣ бо тасдиқ) — дархости воқеӣ
  ба Anthropic/OpenAI-мувофиқ мефиристад, агар API Key дуруст бошад.
- Системаи навбатии калидҳо — дар хатои воқеии квота/HTTP 429 ба калиди
  навбатӣ мегузарад.
- Import/Export (JSON ва ZIP) — воқеӣ.
