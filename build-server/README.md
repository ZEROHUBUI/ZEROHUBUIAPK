# build-server — H2APK (муҳаррики воқеии сохтани APK)

Ин папка коди сервер надорад — H2APK як лоиҳаи ҷудогонаи кушодаманбаъ аст:
https://github.com/HashShin/H2APK (Go).

## Меъморӣ

```
Вебсайти ZEROHUBUIAL (браузер)
        │  fetch/EventSource (мустақим, бе миёнарав)
        ▼
   Сервери H2APK  (localhost:8080 ё сервери шумо)
        │
        ▼
 javac → d8 (dex) → aapt2 → zipalign → apksigner
        │
        ▼
      APK-и воқеӣ
```

ZEROHUBUIAL мустақиман аз браузери корбар бо H2APK гуфтугӯ мекунад
(`js/build-api.js`). Ягон миёнарави сервери ZEROHUBUIAL вуҷуд надорад — аз ин
рӯ маълумоти лоиҳаи корбар ба ҳеҷ ҷои дигар намеравад.

## Роҳандозии худмизбон (тавсияшуда)

1. Клон кунед: `git clone https://github.com/HashShin/H2APK`
2. Талаботро (Go, Android SDK build-tools ва ғ.) тибқи README-и он лоиҳа
   насб кунед.
3. `go build` ва иҷро кунед — тибқи пешфарз дар `http://localhost:8080` кор
   мекунад (портро дар README-и H2APK тафтиш кунед).
4. Дар ZEROHUBUIAL → ТАНЗИМОТ → "Нишонии сервери H2APK" ҳамин нишониро
   ворид кунед.

## Хизмати ҷамъиятӣ (алтернатива, бе назорати шумо)

`https://h2apk.hashcode.win` як нусхаи оммавии H2APK аст. Истифодаи он содда
аст, аммо маънои онро дорад, ки HTML/CSS/JS-и лоиҳаи шумо ба сервери шахси
сеюм фиристода мешавад. Барои лоиҳаҳои ҳассос, худмизбонии H2APK тавсия
дода мешавад (қисми "Бехатарӣ"-и талабот).

## Тасдиқи схемаи дархост (қадами ҳатмии боқимонда)

Тибқи README-и асосии лоиҳа, номи дақиқи майдонҳои JSON-и `/api/build` аз
коди сервер тасдиқ карда нашудааст (баррасии дарахти пурраи GitHub манъ
буд). Барои тасдиқи 100%:

1. H2APK-ро локалӣ роҳандозӣ кунед (боло).
2. UI-и худи H2APK-ро дар браузер кушоед (`http://localhost:8080`).
3. DevTools → Network-ро кушоед, формаро пур карда фиристед.
4. Дархости `POST /api/build`-ро бинед — Payload (JSON body) айнан ҳамон
   номи майдонҳоест, ки H2APK интизор аст.
5. Агар аз он чи дар `js/build-api.js` → `buildFormToPayload()` навишта
   шудааст фарқ кунад, онҷоро мутобиқ созед.

Ин ягона роҳи бидуни тахмин аст — зеро сервер аз рӯи худи коди воқеии он
муайян мешавад, на аз рӯи гумон.
